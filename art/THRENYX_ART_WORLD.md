# THRENYX: "What is Threnyx?" story art

The paintings for the story page (Home → **What is Threnyx?**). There are **13 images**: one header, one per chapter, two inside the text, and a small square for the Home button.

## How to make them

1. Open a **new ChatGPT chat** and paste **one prompt at a time** (each prompt is complete on its own).
2. Make all 13 in the **same chat** if you can, so the final step can package them together. When an image is right, keep it. If you're saving them yourself, use the **exact file name** given, inside a folder called `threnyx-art/ui/`.
   - Example: `threnyx-art/ui/world-hero.png`
3. If ChatGPT gets something wrong, reply in the same chat with the fix (the **Common fixes** at the bottom help), rather than starting over.
4. When all of them are done, package them with the **final prompt** at the bottom of this file (**14. Package the zips**). It makes zip files that are **each under 30 MB**. Send me every zip it makes. Each picture appears in the game as soon as it's added, so batches are fine too.
   - Doing it yourself instead: none of these pictures need transparency, so **JPG is fine** (quality 90 or higher). Keep the same names, just ending in `.jpg`. Put no more than **5 PNGs** or **12 JPGs** in one zip, and check each zip is under 30 MB before sending.

## What makes them match

Every prompt already includes this, so you don't need to paste it separately. It's here so you can check the results:

- **Style:** painterly dark-fantasy oil painting, museum-grade. Deep chiaroscuro, strong rim light, visible brushwork, fine painted grain.
- **The world is made of sound:** faint concentric sound-ripples move through the air from the main light source, like rings from a struck bell.
- **No text of any kind:** no letters, numbers, runes that look like writing, logos, signatures, watermarks, borders or frames.
- **Secrets stay secret:** no recognisable face for the person who strikes the Fork, and the empty portrait stays empty.

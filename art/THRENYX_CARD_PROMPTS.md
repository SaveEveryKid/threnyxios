# THRENYX — Card Art Prompts (all 120, text-free)

One prompt per card. Each makes the **painting only**: no frame, no name, no stats, no text. The game draws the frame, name, stats and rules text on top, so they always match the current balance.

Portrait 1024x1536 PNG. Save each as `cards/<id>.png` (the exact filename in each prompt), then zip the `cards/` folder as `threnyx-cards.zip`. Unzip into `game/client/art/` and list the ids in `manifest.json`.

**Reject and regenerate any image that contains text, letters, numbers, a frame or a border.**
